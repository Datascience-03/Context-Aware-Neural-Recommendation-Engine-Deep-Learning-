Real-Time Inference Flow
🌐
Step 1 - Ingress
POST /recommend
Client sends { customer_id, top_k, context }. Pydantic validates: season in {Winter,Spring,Summer,Fall}, is_weekend in {0,1}, sales_channel_id in {1,2}, top_k in [1,100]. Returns HTTP 422 on invalid input.
Less than 1ms validation
💾
Step 2 - Cache Lookup
Redis Cache-Aside
Cache key = rec:{customer_id}:{season}:{is_weekend}:{top_k}. On cache hit return immediately with cache_hit=true. TTL = 300 seconds. Falls through to embedding lookup on miss.
Less than 2ms on hit
👤
Step 3 - User Embedding Lookup
Embedding Matrix Lookup
O(1) dict lookup: user_id_to_idx[customer_id] then row slice from pre-loaded NumPy matrix shape (N x 64, float32). Cold-start users fall back to L2-normalised mean embedding with cold_start=true.
Less than 0.1ms lookup
🔍
Step 4 - ANN Retrieval
Top-K Vector Search
User embedding (1x64) dot-producted against item index. ExactSearchIndex: brute-force matmul + argsort (accurate, best for M under 50K). IVFIndex: inverted file nlist=32 nprobe=4 (fast, best for M over 50K). Returns top-K (article_id, cosine_score) sorted descending.
2-15ms retrieval
📦
Step 5 - Response and Cache Write
Build RecommendResponse
Ranked list of RecommendationItem(rank, article_id, score) serialised to JSON. Article IDs written to Redis TTL 300s for future cache hits. Response includes retrieval_time_ms, cold_start, cache_hit.
Less than 1ms serialisation
